# 🩺Diabetes Prediction using Machine Learning

## 📌 Overview

This project focuses on predicting whether a person is diabetic or non-diabetic using Machine Learning techniques. The model is trained on medical data such as glucose level, BMI, age, and other health indicators to assist in early detection of diabetes.

Diabetes is a critical health issue worldwide, and early prediction can significantly improve treatment outcomes and lifestyle management.

---

## 🎯 Objectives

* Build a classification model to predict diabetes
* Perform data preprocessing and analysis
* Compare multiple machine learning algorithms
* Evaluate model performance using standard metrics

---

## 📂 Dataset

* Dataset used: **Pima Indians Diabetes Dataset**
* Features include:

  * Pregnancies
  * Glucose
  * Blood Pressure
  * Skin Thickness
  * Insulin
  * BMI
  * Diabetes Pedigree Function
  * Age

This dataset is widely used in ML projects for diabetes prediction. ()
